# Bhumiputram - Self Drive Car Rental (Indore)

Static React website for Bhumiputram's self-drive car rental service.

## Run locally

```sh
cd frontend
yarn install
yarn start
```

## Key files

- `frontend/src/lib/constants.ts` - WhatsApp details, fleet data, and site content.
- `frontend/src/pages/` - Home, Fleet, CarDetail, Pricing, FAQ, and Contact pages.
- `frontend/public/logo-mark.png` - Brand emblem and favicon.

## Notes

- Vehicle data is bundled with the frontend.
- Booking links and the contact form open WhatsApp with a pre-filled message.
- The site stores no customer data and requires no backend, database, login, or payment system.
