# Bhumiputram Car Rental

## Run the website

From this folder, run:

```powershell
npm start
```

Then open http://localhost:3000 in your browser.

The frontend dependencies are already included. If they need to be restored later, run:

```powershell
npm install --prefix bhumiputram/frontend
```

## Other commands

```powershell
npm run build  # Create a production build
npm test       # Run tests
```
